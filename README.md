# Kumbh Darshan ॐ

A multilingual guide to the Kumbh Mela — the world's largest
human gathering. Hand-curated in English, हिंदी, मराठी and संस्कृतम्, plus one-tap machine translation into 100+ languages via the globe button (Google Translate). No frameworks, no build step, no backend: one HTML file.

## What's inside

- **Live countdown** to the next sacred milestone, with Add-to-Google-Calendar and .ics buttons
  on every key bathing (Snan) date
- **Every Kumbh, past & future** — 18 events from the 1895 and 1903 colonial-era melas through
  the 2025 Maha Kumbh (66 crore+ visits) to the Nashik Simhastha and beyond, with exact dates,
  locations, rivers and attendance figures
- **The four sacred cities** — Prayagraj, Haridwar, Nashik–Trimbakeshwar, Ujjain — each with the
  planetary rule (Jupiter / Sun positions) that decides its turn in the cycle
- **Sacred Texts section** — what the Rig Veda, Mahabharata, Bhagavata Purana, Vishnu Purana,
  Matsya Purana, Padma Purana, Valmiki Ramayana, Shiva Purana and Skanda Purana narrate about
  the churning of the ocean, the pot of amrit and the glory of the tirthas
- **Full detail pages** open in a new tab for every event
- **Plan your visit** — rail / air / bus directions per city, budget playbook, stay links
  (IRCTC, Google Maps, Booking.com, MakeMyTrip, OYO) and ghats safety guidance
- **Dark / light theme** (remembers your choice) and full English–Hindi–Marathi–Sanskrit toggle

## Deploying on GitHub Pages

This repository is already set up for GitHub Pages — just:

1. Upload these files to a **public** repository (index.html must be at the root).
2. Go to **Settings → Pages**.
3. Under *Build and deployment*, set Source to **Deploy from a branch**, branch **main**,
   folder **/ (root)**, and save.
4. Your site goes live in a minute or two at
   `https://<your-username>.github.io/<repo-name>/`.

## Updating the site

Replace `index.html` (repo → *Add file* → *Upload files* → commit) — GitHub Pages rebuilds
automatically.

## Notes

- All dates and historical figures are compiled from public web sources (government releases,
  news reports, published calendars). Long-range dates are planetary-cycle projections.
  Please verify with official sources before travelling.
- Devotional content is presented as tradition; historical content as history.
